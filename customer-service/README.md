# Customer Service

Customer profile microservice for Micro-Commerce.

## Endpoints

- GET `/api/customers`
- GET `/api/customers/{id}`
- POST `/api/customers`
- PUT `/api/customers/{id}`

## Database

Uses `customer_db.customer` from `Init_Files/init.sql`.

## Port

`5001`

This service follows the same simple controller/service/repository/DTO/ModelMapper structure used by the existing Micro-Commerce services.
